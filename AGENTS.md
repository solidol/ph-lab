# Вимоги до проєкту

## Призначення

Проєкт містить інтерактивні емулятори фізичних дослідів для виконання лабораторних робіт з фізики.

## Загальні вимоги

Кожна лабораторна робота повинна містити:

1. Емулятор досліду з налаштуваннями параметрів.
2. Елементи керування для введення та зміни даних: поля вводу, повзунки, обертові регулятори тощо, відповідно до потреб досліду.
3. Відображення фізичних формул, що використовуються в досліді та розрахунках.
4. Таблиці для фіксації результатів вимірювань і розрахунків.

## Технології та розгортання

- Використовувати HTML, CSS і JavaScript.
- Забезпечити роботу проєкту як статичного вебсайту на GitHub Pages.
- Емуляція дослідів, введення даних і розрахунки повинні працювати в браузері без обов'язкового серверного бекенду.

## Правила реалізації

- Під час створення або зміни лабораторної роботи дотримуватися всіх загальних вимог вище.
- Узгоджувати параметри емулятора, відображені формули та розрахунки в таблицях.
- Позначати фізичні величини й одиниці вимірювання в елементах керування та таблицях.
