# phlab

Статичний проєкт лабораторних робіт з фізики на HTML, CSS і JavaScript.

## Лабораторна 01

Відбиття та заломлення світла: схема променів із транспортиром, регулювання кута падіння, вибір середовищ і власних показників заломлення, закон Снеліуса, критичний кут та повне внутрішнє відбиття. Результати фіксуються в таблиці, зберігаються в localStorage і експортуються в CSV.

Модель використовує плоску межу однорідних середовищ. Інтенсивність, поляризація, дисперсія та інтерференція не моделюються. Таблиця містить розраховані значення ідеальної моделі, без похибок реального вимірювання. Для нульового кута відношення синусів не визначене.

## Локальний запуск

Запустіть статичний HTTP-сервер у корені проєкту, наприклад `python -m http.server 8000`, та відкрийте http://localhost:8000. ES-модулі потребують HTTP-сервера; відкриття index.html через file:// не підтримується.

Сторонні бібліотеки та збірка не потрібні. За наявності Node.js перевірки запускаються командами `npm test` і `npm run check`. Встановлювати залежності не потрібно.

## GitHub Pages

Завантажте файли в репозиторій GitHub. У **Settings → Pages** виберіть **Deploy from a branch**, потрібну гілку та папку **/(root)**. Відносні шляхи дозволяють працювати як на домені користувача, так і в підкаталозі репозиторію.

## Ручна перевірка

- Змініть кут числовим полем і повзунком: схема та показники мають оновитися синхронно.
- Для повітря → скла за 40° очікується β ≈ 25,37°.
- Для скла → повітря за 50° заломлений промінь відсутній; критичний кут ≈ 41,81°.
- Зафіксуйте вимірювання, перезавантажте сторінку, видаліть один рядок і перевірте CSV.
- Перевірте керування клавіатурою та вигляд на вузькому екрані.
